## F001 資格一覧表示

### １．機能概要

| 項目 | 内容 |
| --- | --- |
| 機能ID | F001 |
| 機能名 | 資格一覧表示 |
| 概要 | 登録済資格を一覧表示する |
| 利用画面 | 資格一覧画面 |

### ２．表示項目

| 項目 | 内容 |
| --- | --- |
| 資格名 | 登録済資格名を表示する |
| 取得日 | 資格取得日を表示する |
| 最終更新日 | 資格更新日を表示する |
| 難易度 | 資格難易度を表示する |
| 一言 | 資格に関する感想を表示する |

### ３．処理内容

1. 資格一覧画面を表示する
2. QUALIFICATIONテーブルを検索する
3. 資格情報を取得する
4. 取得結果を表示する

### ４．取得テーブル

#### QUALIFICATION

- qualification_id
- qualification_name
- acquisition_date
- last_update_date
- difficulty_id
- comment

#### DIFFICULTY_MASTER

- difficulty_id
- difficulty

### ５．SQL

```sql
SELECT 
    q.qualification_id,
    q.qualification_name,
    q.acquisition_date,
    q.last_update_date,
    d.difficulty,
    q.comment
FROM QUALIFICATION q
INNER JOIN DIFFICULTY_MASTER d
    ON q.difficulty_id = d.difficulty_id
ORDER BY q.acquisition_date DESC;
```

### ６．正常処理

- 資格一覧を表示する

### ７．異常処理

- DB接続失敗時はエラーメッセージを表示する
- データ取得失敗時はエラーメッセージを表示する

## F002 資格登録

### １．機能概要

| 項目 | 内容 |
| --- | --- |
| 機能ID | F002 |
| 機能名 | 資格登録 |
| 概要 | 資格情報を新規登録する |
| 利用画面 | 資格登録画面 |

### ２．登録項目

| 項目 | 内容 |
| --- | --- |
| 資格名 | 資格名を登録する |
| 取得日 | 資格取得日を登録する |
| 難易度 | 資格難易度を登録する |
| 一言 | 資格に関する感想を登録する |

### ３．入力チェック

| 項目 | 内容 | エラーメッセージ |
| --- | --- | --- |
| 資格名 | 未入力不可 | 資格名を入力してください |
| 取得日 | 未入力不可 | 取得日を入力してください |
| 難易度 | 未選択不可 | 難易度を選択してください |
| 一言 | 500文字以内 | 500文字以内で入力してください |

### ４．処理内容

1. 資格登録画面を表示する
2. 利用者が資格情報を登録する
3. 登録ボタンを押下する
4. 入力チェックを行う
5. QUALIFICATIONテーブルへ資格情報を登録する
6. 登録完了メッセージを表示する
7. 資格一覧画面へ遷移する

### ５．登録テーブル

#### QUALIFICATION

- qualification_id ※システムで自動採番する
- qualification_name
- acquisition_date
- difficulty_id
- comment
- created_at ※システムで自動付与する

### ６．SQL

```sql
INSERT INTO QUALIFICATION (
    qualification_id,
    qualification_name,
    acquisition_date,
    difficulty_id,
    comment,
    created_at
)
VALUES (
    qualification_seq.NEXTVAL,
    ?,
    ?,
    ?,
    ?,
    SYSDATE
);
```

### ７．正常処理

- 新規資格情報を登録する
- 登録完了メッセージを表示する
- 資格一覧画面へ遷移する

### ８．異常処理

- 入力チェックエラー
- DB接続エラー
- 登録失敗エラー

## F005 資格難易度グラフ表示

### １．機能概要

| 項目 | 内容 |
| --- | --- |
| 機能ID | F005 |
| 機能名 | 資格難易度グラフ表示 |
| 概要 | 難易度別の資格数をグラフ表示する |
| 利用画面 | グラフ画面 |

### ２．表示対象

| 項目 | 内容 |
| --- | --- |
| 資格難易度 | 難易度ごとの資格数をグラフ表示する |

### ３．処理内容

1. 資格グラフ画面を表示する
2. QUALIFICATIONテーブルから資格情報を取得する
3. DIFFICULTY_MASTERテーブルから難易度情報を取得する
4. 難易度ごとの資格数を集計する
5. グラフデータを生成する
6. グラフ画面に表示する

### ４．取得テーブル

#### QUALIFICATION

- qualification_id(PK)
- difficulty_id

#### DIFFICULTY_MASTER

- difficulty_id
- difficulty

### ５．SQL

```sql
SELECT 
    d.difficulty,
    COUNT(*) AS qualification_count
FROM QUALIFICATION q
INNER JOIN DIFFICULTY_MASTER d
    ON q.difficulty_id = d.difficulty_id
GROUP BY
    d.difficulty
ORDER BY
    d.difficulty_id;
```

### ６．正常処理

- 難易度ごとの合計数を表示する
- 資格難易度グラフを表示する

### ７．異常処理

- DB接続エラー発生時はエラーメッセージを表示する
- データ取得失敗時はエラーメッセージを表示する
