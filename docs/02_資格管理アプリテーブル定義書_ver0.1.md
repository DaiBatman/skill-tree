# テーブル定義書

## テーブル名：QUALIFICATION（資格管理テーブル）

| 論理名 | 物理名 | 型 | PK | NULL | 説明 |
| --- | --- | --- | --- | --- | --- |
| 資格ID | qualification_id | NUMBER | ○ | × | 主キー |
| 資格名 | qualification_name | VARCHAR(100) | | × | 資格名 |
| 取得日 | acquisition_date | DATE | | × | 資格取得日 |
| 最終更新日 | last_update_date | DATE | | ○ | 資格更新日 |
| 難易度ID | difficulty_id | NUMBER | | × | 資格難易度(F~SSS) |
| 一言感想 | comment | VARCHAR(500) | | ○ | 感想 |
| 登録日時 | created_at | DATE | | × | 登録日 |

| 論理名 | 物理名 | 型 | PK | NULL | 説明 |
| --- | --- | --- | --- | --- | --- |
| 難易度ID | difficulty_id | NUMBER | ○ | × | 主キー |
| 難易度 | difficulty | VARCHAR(3) | | × | 資格難易度(F~SSS) |
